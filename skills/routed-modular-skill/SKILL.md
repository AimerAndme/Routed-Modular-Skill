# Routed Modular Skill

所有路径相对本文件所在目录；工具调用使用解析后的绝对路径。

1. 读取 [模块索引](catalog.json)，或运行 `python3 scripts/rms.py list`。
2. 根据用户任务和索引选择明确模块 ID。若多个含义无法区分，先澄清；不要默认选择第一个模块。
3. 运行 `python3 scripts/rms.py load <id>`，只读取该模块指南；需要多个模块时逐个加载。
4. 按指南读取 [公共契约](shared/CONTRACT.md)，准备并校验输入。
5. 使用执行器运行已选模块。不要为常规执行读取脚本源码，也不要自行重写已有算法。
6. 检查退出状态和结构化结果，再向用户呈现。失败不得当作成功结果。

仅在指南明确需要时读取模块附属资料。不要递归读取全部 modules/。新增业务能力需同步更新索引、指南、脚本及测试。
